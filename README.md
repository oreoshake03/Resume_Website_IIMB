# Aditya Prakash

My academic website, with information about my education, research, projects, and technical interests.

## Website

The site has sections for research experience, projects, education, technical skills, coursework, leadership, and contact details. A PDF version of my CV is available from the homepage.

Built with HTML, CSS, and a little JavaScript. The layout uses CSS Grid and Flexbox and adjusts to different screen sizes. No framework or build tools are required.

## Run locally

Download the project and open `index.html` in a web browser.

## Hosting

The website is set up for GitHub Pages.

1. Upload `index.html`, the `assets` folder, and `.nojekyll` to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` (or the repository's default branch), and select `/ (root)`.
4. Save the settings. GitHub will show the published website address in the Pages section.

If the repository is already connected to GitHub Pages, committing the updated files is enough to publish the changes.
